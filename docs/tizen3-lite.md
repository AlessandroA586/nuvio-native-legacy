# Experimental Tizen 3 lite

## Feasibility checkpoint

The existing package cannot run on 2017 Samsung TVs: it requires WebAssembly
and pthreads/SharedArrayBuffer. Samsung's [web engine table](https://developer.samsung.com/smarttv/develop/specifications/web-engine-specifications.html)
identifies Tizen 3.0 as Chromium M47. This is pre-WebAssembly (Chrome 57).
WebGL 1, typed arrays, Promise and fetch are usable; the engine has partial ES2015
support, not ES2017 async functions. ES5 output is the conservative target.

No asm.js build exists in this checkout. `tools/tizen.sh --vidaa --um-fio`
already uses `src/fio1.c` cooperative fibers and asynchronous fetch without
pthreads, but still emits WASM. The Tizen renderer already caps WebGL at 1.
The normal glue is generated by emcc from C/EM_JS/EM_ASYNC_JS and transpiled
with esbuild for Chrome 69; this is insufficient for M47. esbuild alone does
not lower all ES2015 syntax to ES5.

A local Emscripten 6.0.9 minimal C probe successfully compiled with
`-sWASM=0 -sLEGACY_VM_SUPPORT=1 -sENVIRONMENT=web` (rc 0). Modern Emscripten
uses wasm2js, not the historical fastcomp asm.js backend. Its output includes
a local WebAssembly API shim; the browser must not need a native WASM API.
Asyncify/fibers and whole-app performance still need proof.

Remaining blockers: whole-app JS compilation/transpilation, missing modern
browser APIs (notably createImageBitmap/OffscreenCanvas), JS parse/JIT cost,
fixed heap plus GPU/browser memory, AVPlay firmware differences, old TLS roots,
and streaming codec/DRM compatibility. There is no portable documented web-app
RAM allowance to treat as a guarantee. Desktop startup cannot establish TV
performance, playback, or memory safety.

The spike will remain opt-in, use package ID NuvioTV003, retain the Samsung
AVPlay backend, and produce an unsigned archive without calling Tizen tools.
Normal .wgt and .tpk build behavior must remain unchanged.

## Status

Research checkpoint only. Whole-app build, no-WASM smoke, size, final verdict,
and sideload instructions will be recorded after the experiment.
